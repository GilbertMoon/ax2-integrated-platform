## 3. 최종 결과

### 3-1. Slack 사용자 매핑 기준
* LMS의 사용자 ID를 기준으로 4조 `ax_evaluation` DB의 `notifications_slackidentity.user_id`를 조회한다.
* 활성화된 Slack Identity(`is_active=True`)가 존재하는 경우 해당 Slack Member ID를 사용한다.
* Slack 계정이 연결되지 않은 경우 개인 DM 발송을 실패 처리하고 LMS의 기존 과제 제출 흐름에는 영향을 주지 않도록 구성한다.

### 3-2. Slack 개인 DM 처리 기준
* Slack Bot Token을 사용하여 `conversations.open`으로 학생과의 DM 채널을 연다.
* `chat.postMessage`를 이용하여 개인 DM을 발송한다.
* 알림 제목, 과제명, 상세 링크를 공통 포맷으로 구성한다.

### 3-3. 과제 제출 알림 기준
* 학생이 과제 제출을 완료하면 제출 처리 후 Slack 개인 DM을 발송한다.
* 현재 구현 범위는 **과제 제출 완료 알림**이다.
* 미제출자 대상 독려 메시지는 별도 요구사항 확인 후 추가 구현 대상으로 분리한다.
