# P6 황지나 작업 정리

## 1. 담당 범위

- 3조 프로젝트 기능 분석 및 통합
- 3조 PRD / ERD 구조 확인
- 통합 플랫폼의 메인 ERD 반영 지원
- DevOps 관점의 개발·운영 환경 확인 및 통합 지원

---

## 2. 8/27 작업 완료 내용

### 2-1. 각 조 PRD / ERD 취합

각 조에서 전달받은 PRD와 ERD를 확인하여 프로젝트별 기능과 데이터 구조를 비교했다.

- 각 조의 주요 기능 및 데이터 영역 확인
- 공통 데이터와 조별 고유 데이터 구분
- 기존 Core 기준과의 연결 가능성 검토
- 각 조 ERD를 통합 ERD에 반영할 수 있도록 구조 정리

### 2-2. 메인 ERD 통합 작업

각 조에서 전달받은 ERD를 바탕으로 최종 통합 ERD에 필요한 내용을 반영했다.

- 공통 데이터 구조의 중복 여부 확인
- 각 조 고유 기능에 필요한 데이터 영역 반영
- 조별 데이터가 통합 플랫폼에서 연결될 수 있도록 관계 구조 검토
- 최종 통합 구조를 기준으로 이후 개발 및 DB 작업이 진행될 수 있도록 정리

### 2-3. 작업 결과

> 각 조의 PRD/ERD를 개별적으로 관리하는 단계에서 벗어나, 통합 플랫폼 기준의 메인 ERD에 반영할 수 있는 구조로 정리했다.

---

## 3. 8/28 오늘 작업 내용

### 3-1. 메인 시스템 및 ERD 상태 확인

- 메인 시스템 현재 동작 상태 확인
- 통합한 메인 ERD 구성 및 반영 상태 확인
- 통합 과정에서 누락되거나 추가 확인이 필요한 부분 점검

### 3-2. 3조 ERD 및 데이터 연계 협의

- 3조 ERD 구조 재검토
- 메인 ERD와 비교하여 수정·보완이 필요한 부분 확인
- 공통 데이터와 3조 고유 데이터 간 관계 재확인
- 3조의 Core 데이터 연동 계획(User, EvaluationRound, Team) 확인

### 3-3. User 정보 VIEW 연계

통합 ERD를 기반으로 구성된 User 정보 VIEW를 3조에 공유하고, 실제 개발에서 활용할 수 있는지 확인했다.

- 3조 기능 개발에 필요한 User 정보가 현재 VIEW 컬럼으로 충분한지 확인
- 3조는 현재 제공된 VIEW 컬럼으로 필요한 사용자 정보를 충분히 활용할 수 있다고 확인
- 실제 구현 시 제공 VIEW를 사용하는 방향으로 협의
- VIEW 사용 중 추가 데이터가 필요하거나 구조상 문제가 발생할 경우 추가 협의하기로 확인

### 3-4. 서버 환경 관련 협의

3조에서 현재 서버를 계속 사용하는지 문의하여, 향후 신규 컴퓨터가 제공되면 해당 환경을 기준으로 새로운 서버를 구축하는 방향을 공유했다.

---

## 4. 오늘 작업 결과

> 통합 ERD와 메인 시스템의 현재 상태를 확인하고, 3조 ERD와 Core 데이터 연계 방향을 검토했다. 또한 통합 ERD 기반 User 정보 VIEW를 3조에 공유하여 필요한 사용자 정보가 충분한지 확인했으며, 3조는 제공 VIEW를 활용하는 방향으로 개발을 진행하기로 협의했다.
