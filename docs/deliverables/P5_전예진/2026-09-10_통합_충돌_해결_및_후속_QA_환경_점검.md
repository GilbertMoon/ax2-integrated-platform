확인 결과 Slack 전송 기능 자체의 장애라기보다 현재 테스트 사용자와 Slack 계정 매핑 상태에 의해 발송 대상이 결정되는 구조로 판단하였다.

따라서 LMS 통합 코드 자체의 결함과는 분리하여 확인하였다.

### 2.6 공용 DB 접속 문제 확인

공용 DB 접속 실패 원인을 확인하기 위해 다음 명령을 실행하였다.

```powershell
Test-NetConnection 10.2.16.73 -Port 5432
```

확인 결과:

```text
ComputerName     : 10.2.16.73
RemoteAddress    : 10.2.16.73
RemotePort       : 5432
InterfaceAlias   : Wi-Fi
SourceAddress    : 10.2.16.203
PingSucceeded    : False
TcpTestSucceeded : False
```

`TcpTestSucceeded : False`가 확인되어 현재 문제는 Django ORM이나 LMS 통합 코드 이전 단계에서 발생하는 네트워크/DB 접근 문제로 분리하였다.
