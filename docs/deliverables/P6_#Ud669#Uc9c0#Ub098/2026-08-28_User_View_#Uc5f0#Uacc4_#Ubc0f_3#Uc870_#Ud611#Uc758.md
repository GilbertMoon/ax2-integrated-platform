# User View 연계 및 3조 협의

- 작성자: **P6 황지나**
- 작성일: **2026-08-28**
- 관련 범위: **통합 ERD / User 정보 View / 3조 데이터 연계**

## 1. 작업 목적

통합 ERD를 기준으로 구성된 User 정보 View를 3조에 공유하고, 3조의 개발 과정에서 필요한 사용자 정보 및 Core 데이터 연계 방향을 확인한다.

## 2. 진행 내용

### 2-1. User 정보 View 공유

- 통합 ERD를 기반으로 구성된 User 정보 View를 3조에 공유
- 3조 기능 개발에 필요한 사용자 정보가 현재 View 컬럼으로 충분한지 확인
- 3조에서 필요한 정보는 현재 제공된 View 컬럼으로 충분하다는 답변 확인

### 2-2. 3조 Core 데이터 연동 방향 확인

3조 PRD에서 계획한 `User`, `EvaluationRound`, `Team` Core 테이블 연동 방향을 확인했다.

- User: PRD 소유자, 피드백 작성자, 브레인스토밍 참여자 식별용 참조
- EvaluationRound: PRD가 속한 회차 연결
- Team: 팀 단위 프로젝트 연결
- 개인 프로젝트도 고려하여 `round_id`, `team_id`는 Nullable로 설정하는 방향 확인
- 실제 구현 시 제공된 View를 사용하는 방향으로 협의

### 2-3. View 활용 방식 협의

원본 테이블을 직접 JOIN하기보다는 제공된 View를 조회하는 권장 방식에 대해 안내했다.

3조에서는 해당 권장 방식에 맞춰 개발을 진행해보고, 사용 과정에서 불편한 점이나 추가 데이터가 필요한 경우 협의하기로 했다.

### 2-4. 서버 환경 관련 협의

3조에서 기존 서버를 계속 사용하는지 문의하였고, 신규 컴퓨터가 제공되면 해당 환경을 기준으로 새로운 서버를 구축하는 방향을 공유했다.

## 3. 확인 결과

- 현재 제공한 User 정보 View의 컬럼은 3조 기능 개발에 충분함
- 3조는 제공된 View를 실제 구현에 활용하는 방향으로 진행
- 추가 데이터 요구사항이나 구조적 문제가 발생할 경우 추후 협의
- 신규 컴퓨터 제공 시 새로운 서버 환경을 구축하는 방향 공유
