## 2. 8/27 작업 완료 내용

### 2-1. 각 조 PRD / ERD 취합

각 조에서 전달받은 PRD와 ERD를 확인하여 프로젝트별 기능과 데이터 구조를 비교했다.

- 각 조의 주요 기능 및 데이터 영역 확인
- 공통 데이터와 조별 고유 데이터 구분
- 기존 4조 Core 기준과의 연결 가능성 검토
- 각 조 ERD를 통합 ERD에 반영할 수 있도록 구조 정리

### 2-2. 메인 ERD 통합 작업

각 조에서 전달받은 ERD를 바탕으로 최종 통합 ERD에 필요한 내용을 반영했다.

- 공통 데이터 구조의 중복 여부 확인
- 각 조 고유 기능에 필요한 데이터 영역 반영
- 조별 데이터가 통합 플랫폼에서 연결될 수 있도록 관계 구조 검토
- 최종 통합 구조를 기준으로 이후 개발 및 DB 작업이 진행될 수 있도록 정리

### 2-3. 작업 결과

> 각 조의 PRD/ERD를 개별적으로 관리하는 단계에서 벗어나, 통합 플랫폼 기준의 메인 ERD에 반영할 수 있는 구조로 정리했다.

## 4. 2~3분 설명용 요약

이번 작업에서 저는 P6 담당으로 3조 기능 통합과 통합 플랫폼의 데이터 구조 정리를 담당했습니다.

먼저 각 조에서 전달받은 PRD와 ERD를 확인했습니다. PRD를 통해 각 조에서 어떤 기능을 제공하는지 파악하고, ERD를 통해 실제로 어떤 데이터와 테이블이 필요한지를 비교했습니다.

그 다음 각 조의 구조를 그대로 합치는 것이 아니라, 기존 4조 Core를 기준으로 공통 데이터와 각 조의 고유 데이터를 구분했습니다. 특히 User, Student, Team처럼 여러 조에서 공통으로 사용할 수 있는 데이터는 중복되지 않도록 통합 기준을 확인하고, 각 조만의 기능에 필요한 데이터는 별도 영역으로 유지하는 방향으로 정리했습니다.

이후 각 조에서 전달받은 ERD 내용을 메인 ERD에 반영하여 전체 플랫폼에서 사용할 수 있는 통합 데이터 구조를 만드는 작업을 진행했습니다. 이를 통해 이후 DB 설계나 기능 통합을 진행할 때 각 조별 ERD를 따로 보는 것이 아니라 하나의 메인 ERD를 기준으로 작업할 수 있도록 했습니다.

오늘은 어제 통합한 메인 ERD를 다시 검토하면서 3조 PRD와 비교해 누락된 기능이나 데이터가 없는지 확인하고, 공통 데이터와 3조 고유 데이터의 연결 관계를 최종적으로 점검할 예정입니다. 이후 3조 프로젝트의 실제 실행 여부와 핵심 화면도 확인하고, Windows 11 Pro 서버 환경 점검까지 이어갈 계획입니다.
