## 1. 작업 목적

ERD 튜터님 피드백을 반영한 TO-BE 통합 ERD를 정리하고, 통합 프로젝트의 로컬 개발환경을 구축했다. 또한 3조 개발 진행 상태 및 View 활용 가능 여부를 확인하고, 각 조의 Slack 연동 요구사항을 조사했다.

## 2. 진행 내용

### 2-1. TO-BE 통합 ERD 수정

튜터님 피드백을 반영하여 새로운 통합 TO-BE ERD를 작성했다.

- 산출물: `docs/erd/TO_BE_ERD_integrated_2026-08-31.mermaid`
- 기존 통합 구조를 기준으로 피드백 반영본을 별도 파일로 관리

### 2-2. 통합 프로젝트 로컬 개발환경 구축

기존 프로젝트 파일을 새로 구성한 `ax2-integrated-platform` 레포에 통합하고, 로컬에서 개발 가능한 환경을 구성했다.

- `develop` 브랜치 기준으로 작업 내용 확인
- `feature/p6-jina` 작업 브랜치 생성
- Python 가상환경(`.venv`) 생성
- 프로젝트 의존성 설치
- `.env` 생성 및 공용 DB 설정
- Django `check` 실행
- DB `migrate` 확인
- Django `runserver` 실행 및 로컬 서버 정상 구동 확인

> 현재 단계에서는 P6의 실제 기능 개발보다 통합 프로젝트의 개발환경을 구성하고 정상 구동 여부를 확인하는 데 초점을 두었다.

### 2-3. 3조 개발 상태 및 User View 활용 확인

전날 계획한 항목을 기준으로 3조와 확인했다.

- 3조 개발 과정에서 현재 제공된 User View를 실제 기능에서 사용하고 있는지 확인
- 현재는 개발 단계에서 해당 기능을 사용하지 않고 있음을 확인
- View 사용 과정에서 추가 요구사항이나 불편사항이 있는지 확인
- 현재 팀 연동 구현 가능 여부를 문의했고, 통합 프로젝트 계획에 포함된 내용으로 구현 가능하다고 안내

### 2-4. Slack 연동 요구사항 조사

각 조의 요구사항 중 Slack 연동 기능 담당을 맡아 현재 공유된 요구사항을 조사했다.

확인된 요구사항:

- **1조:** 게임에 오랫동안(7일) 접속하지 않은 사용자에게 Slack 알림을 보내는 기능 필요
- **2조:** LMS에서 과제를 미제출한 학생에 대해 튜터가 버튼을 눌러 과제 제출을 독려하는 기능 필요
- **3조:** 현재 Slack 연동 요구사항 없음
