# 신규 프로젝트 차수 생성 Web 화면

- 담당: P3 김종복
- 작업일: 2026-09-04
- Branch: `feature/p3-jb`
- 상태: 구현 내용 산출물 정리

## 1. 작업 목적

프로젝트 회차 관리 화면에서 신규 프로젝트 차수를 생성할 수 있도록 Web 화면의 입력 및 이동 구조를 정리한다.

이번 작업의 프로젝트 차수 정의는 별도의 `ProjectRound` 테이블을 추가하는 방식이 아니다. 현재 DB의 `rounds_evaluationround` 각 회차를 프로젝트 회차로 보고, 연결된 `project_info`의 프로젝트 정보를 함께 관리한다.

## 2. 회차 데이터 구조

```text
rounds_evaluationround
        │
        │ project_info.evaluationround_id
        ▼
project_info
```

- `rounds_evaluationround`: 회차의 기본 및 평가 관련 정보
- `project_info`: 프로젝트명, 프로젝트 설명, 팀 구성 기간 등 프로젝트 정보
- 신규 프로젝트 차수 생성 시 하나의 회차를 생성하고 해당 회차에 프로젝트 정보를 연결한다.

## 3. Web 화면 구성

신규 프로젝트 차수 생성 화면에서는 다음 정보를 입력할 수 있도록 구성한다.

| 항목 | 데이터 위치 | 설명 |
|---|---|---|
| 프로젝트명 | `project_info.name` | 프로젝트 차수의 명칭 |
| 프로젝트 설명 | `project_info.description` | 프로젝트 설명 |
| 팀 구성 시작일 | `project_info.team_start` | 프로젝트 팀 구성 시작일 |
| 팀 구성 종료일 | `project_info.team_end` | 프로젝트 팀 구성 종료일 |
| 평가 회차 정보 | `rounds_evaluationround` | 해당 프로젝트에 연결되는 평가 관련 정보 |

## 4. 화면 처리 흐름

```text
프로젝트 회차 관리
        ↓
[신규 프로젝트 차수 생성]
        ↓
프로젝트 정보 입력
        ↓
입력값 검증
        ↓
Backend 신규 회차 생성
        ↓
project_info 연결
        ↓
생성 완료
        ↓
프로젝트 회차 상세 화면
```

## 5. 입력값 검증

- 프로젝트명 입력 여부 확인
- 프로젝트 기간의 시작일/종료일 확인
- 시작일은 종료일보다 이전이어야 함
- 프로젝트 정보와 평가 회차 정보가 동일한 회차를 기준으로 연결되어야 함

DB의 `project_info`에는 다음 기간 조건이 정의되어 있다.

```text
team_start와 team_end가 모두 NULL이거나,
둘 다 입력되고 team_start < team_end
```

## 6. 프로젝트 회차와 평가 회차의 화면 관계

프로젝트 회차는 평가 회차와 별도의 회차가 아니다.

```text
/manage/rounds/
    ↓
프로젝트 관점의 회차 관리
    ↓
/manage/rounds/<id>/
    ↓
연결된 평가 회차
    ↓
/manage/evaluation-rounds/<id>/
    ↓
평가 회차 관리
```

따라서 신규 프로젝트 차수 생성 후 생성된 동일 회차 ID를 기준으로 평가 회차 관리 기능과 연결한다.

## 7. 관련 Web 파일

- `templates/rounds/project_list.html`
- `templates/rounds/project_detail.html`
- `templates/rounds/form.html` (평가 회차 생성/수정 화면과의 연계 검토 대상)
- `templates/includes/sidebar.html`

## 8. DB 변경 여부

이번 Web 화면 작업에서는 신규 `ProjectRound` 테이블을 생성하지 않는다.

기존 다음 구조를 그대로 사용한다.

- `rounds_evaluationround`
- `project_info`

따라서 Web 화면 변경만으로 새로운 DB migration을 요구하는 구조 변경은 포함하지 않는다.
