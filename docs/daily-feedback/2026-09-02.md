# 전체 진행 요약

현재 4조는 **통합 기준 수립 및 개별 기능 개발 단계에서 실제 소스 통합 단계로 전환 중**이다.

- **P1:** 통합 기준 및 전체 조율
- **P2:** User / 권한 / 근태
- **P3:** DB / ERD / Migration
- **P4:** OAuth / 인증
- **P5:** 통합 QA / Regression
- **P6:** Slack / ERD / 3조 연계

현재 Critical Blocker는 없으나, 실제 코드가 `develop`에 통합되기 시작하면 각 담당 업무에 대해 **PR → 코드 변경 확인 → DB 영향 확인 → 실행 테스트 → Cross Check → Regression Test** 순으로 최종 검증할 예정이다.
