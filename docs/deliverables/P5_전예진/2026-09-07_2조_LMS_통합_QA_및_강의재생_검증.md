# 2026-09-07 2조 LMS 통합 QA 및 강의 재생 검증

## 1. 목적

- 2조 LMS가 4조 통합 환경에서 정상적으로 동작하는지 학생 사용자 기준으로 확인한다.
- 강의·교안 학습 및 과제 연동 흐름을 점검한다.
- 통합 환경에서 발생한 강의 재생 오류의 발생 구간을 확인하고 해결한다.
- 서버 로그 및 실제 화면 동작을 기준으로 통합 후 LMS 기능의 정상 여부를 검증한다.
- 최종 Regression 테스트를 위한 LMS 주요 기능 상태를 확인한다.

## 2. 오늘 수행 내용

### 2.1 2조 LMS 학생 기능 통합 QA

- 학생 계정으로 LMS 로그인 및 페이지 접근 확인
- 학생 대시보드 및 강의·교안 학습 영역 접근 확인
- 일자별 강의 목록 조회 확인
- 등록된 강의 선택 및 상세 화면 진입 확인
- 강의와 연결된 과제/콘텐츠 접근 흐름 확인
- 과제 제출 URL 접근 및 Preview 화면 전환 확인

### 2.2 강의 재생 기능 테스트

2조 측 테스트 환경에서는 등록된 강의가 정상적으로 재생되는 것을 확인했으나, 통합 환경에서 동일 기능을 테스트하는 과정에서 강의 재생 영역에 아래 오류가 발생하였다.

```text
127.0.0.1에서 연결을 거부했습니다.
```

강의 페이지 자체의 서버 응답 여부와 영상 재생 영역의 요청 흐름을 분리하여 확인하였다.

### 2.3 Django 서버 요청 로그 확인

강의 및 과제 연동 과정에서 서버 로그를 확인하였다.

```text
GET /lecture/2/ HTTP/1.1 200
GET /assignments/7/submit/ HTTP/1.1 302
GET /assignments/7/preview/ HTTP/1.1 200
GET /lecture/3/ HTTP/1.1 200
GET /assignments/7/submit/ HTTP/1.1 302
GET /assignments/7/preview/ HTTP/1.1 200
```

확인 결과:
- `/lecture/2/` 및 `/lecture/3/` 요청 정상 응답
- 강의 페이지 요청 상태 `200` 확인
- `/assignments/7/submit/` 요청 후 Redirect 발생 확인
- `/assignments/7/submit/` 응답 상태 `302` 확인
- Redirect 이후 `/assignments/7/preview/` 접근 확인
- Preview 페이지 응답 상태 `200` 확인

따라서 Django 서버 자체가 중단된 상태가 아니라, 강의 재생 영역 내부의 연결 구조를 추가 확인할 필요가 있음을 확인하였다.

### 2.4 강의 iframe 구조 확인

브라우저 개발자 도구를 통해 강의 재생 영역의 HTML 구조를 확인하였다.

```html
<iframe
    src="http://127.0.0.1:8000/assignments/7/submit/"
    title="dd"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
    referrerpolicy="strict-origin-when-cross-origin"
    allowfullscreen>
</iframe>
```

강의 재생 영역이 영상 파일을 직접 호출하는 구조가 아니라 과제 제출 URL을 iframe으로 호출하고 있는 것을 확인하였다.

```text
강의 페이지
    ↓
iframe
    ↓
/assignments/7/submit/
    ↓
302 Redirect
    ↓
/assignments/7/preview/
    ↓
Preview 화면
```

이를 기준으로 강의 페이지 자체의 문제와 iframe 내부 콘텐츠 연결 문제를 구분하여 점검하였다.

### 2.5 강의 재생 문제 해결

- 통합 환경에서 발생한 강의 재생 문제의 발생 구간 확인
- 강의 페이지 및 과제 Preview 연결 구조 점검
- 관련 설정 및 연결 상태 확인
- 강의 재생 문제 수정 및 해결
- 수정 후 통합 환경에서 강의 기능 재확인
