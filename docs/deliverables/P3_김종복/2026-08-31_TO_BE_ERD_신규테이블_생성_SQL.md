# TO-BE ERD 신규 테이블 생성 SQL 산출물

- 프로젝트: `ax2-integrated-platform`
- 담당: P3 김종복
- 기준일: 2026-08-31
- 목적: 현재 PostgreSQL DB에 이미 존재하는 테이블은 변경하지 않고, 통합 TO-BE ERD에 정의되어 있으나 현재 DB ERD에 없는 테이블만 생성

## 1. 산출물 목적

통합 TO-BE ERD v1 기준으로 현재 DB에 존재하지 않는 테이블을 식별하고, 기존 Core 테이블과의 FK 관계 및 개인/팀 대상 무결성 규칙을 반영한 PostgreSQL `CREATE TABLE` SQL을 작성한다.

### 기존 Core 기준

- `accounts_user.id`: 사용자/학생 공통 Master ID
- `rounds_roundparticipant.id`: 특정 평가 Round의 참가 이력
- 근태/얼굴인식: `accounts_user.id` 기준
- Round/Team 이력이 필요한 기능만 `rounds_roundparticipant` 참조

## 2. 현재 DB에 이미 존재하여 생성에서 제외한 핵심 테이블

- `accounts_user`
- `rounds_evaluationround`
- `rounds_roundparticipant`
- `teams_team`
- `teams_teammembership`

그 외 Django/Allauth/Axes/감사/공지/알림/기존 리뷰 관련 테이블도 현재 DB ERD에 존재하므로 이번 신규 생성 SQL 대상에서 제외한다.

## 4. PostgreSQL 생성 SQL

> 기존 테이블을 DROP하거나 ALTER하지 않는다. `CREATE TABLE IF NOT EXISTS`를 사용한다.

```sql
BEGIN;

CREATE EXTENSION IF NOT EXISTS pgcrypto;

-- ==========================================================
-- 1조 게임 / 학습
-- ==========================================================

CREATE TABLE IF NOT EXISTS cg_users (
    id BIGINT PRIMARY KEY,
    balance INTEGER NOT NULL DEFAULT 0,
    mileage INTEGER NOT NULL DEFAULT 0,
    house_level INTEGER NOT NULL DEFAULT 1,
    wallpaper_item_id INTEGER,
    floor_item_id INTEGER,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_cg_users_user
        FOREIGN KEY (id) REFERENCES accounts_user(id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS concepts (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    description TEXT
);

CREATE TABLE IF NOT EXISTS tasks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    concept_id INTEGER NOT NULL,
    type VARCHAR(50) NOT NULL,
    difficulty VARCHAR(50) NOT NULL,
    template_code TEXT,
    test_cases TEXT,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    CONSTRAINT fk_tasks_concept
        FOREIGN KEY (concept_id) REFERENCES concepts(id) ON DELETE RESTRICT
);

CREATE TABLE IF NOT EXISTS attendances (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id BIGINT NOT NULL,
    check_in_date DATE NOT NULL,
    streak_count INTEGER NOT NULL DEFAULT 0,
    CONSTRAINT fk_attendances_user
        FOREIGN KEY (user_id) REFERENCES accounts_user(id) ON DELETE CASCADE,
    CONSTRAINT uq_attendances_user_date
        UNIQUE (user_id, check_in_date)
);

CREATE TABLE IF NOT EXISTS user_proficiency (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id BIGINT NOT NULL,
    concept_id INTEGER NOT NULL,
    proficiency_level INTEGER NOT NULL DEFAULT 0,
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_user_proficiency_user
        FOREIGN KEY (user_id) REFERENCES accounts_user(id) ON DELETE CASCADE,
    CONSTRAINT fk_user_proficiency_concept
        FOREIGN KEY (concept_id) REFERENCES concepts(id) ON DELETE CASCADE,
    CONSTRAINT uq_user_proficiency_user_concept
        UNIQUE (user_id, concept_id)
);

CREATE TABLE IF NOT EXISTS task_attempts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id BIGINT NOT NULL,
    task_id UUID NOT NULL,
    submitted_code TEXT,
    status VARCHAR(50),
    is_correct BOOLEAN NOT NULL DEFAULT FALSE,
    feedback_message TEXT,
    used_hint BOOLEAN NOT NULL DEFAULT FALSE,
    attempted_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_task_attempts_user
        FOREIGN KEY (user_id) REFERENCES accounts_user(id) ON DELETE CASCADE,
    CONSTRAINT fk_task_attempts_task
        FOREIGN KEY (task_id) REFERENCES tasks(id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS rooms (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    host_user_id BIGINT NOT NULL,
    title VARCHAR(255) NOT NULL,
    status VARCHAR(50) NOT NULL,
    max_participants INTEGER NOT NULL DEFAULT 2,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_rooms_host_user
        FOREIGN KEY (host_user_id) REFERENCES accounts_user(id) ON DELETE RESTRICT,
    CONSTRAINT chk_rooms_max_participants
        CHECK (max_participants > 0)
);

CREATE TABLE IF NOT EXISTS room_participants (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    room_id UUID NOT NULL,
    user_id BIGINT NOT NULL,
    team_id BIGINT,
    current_score INTEGER NOT NULL DEFAULT 0,
    is_ready BOOLEAN NOT NULL DEFAULT FALSE,
    joined_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_room_participants_room
        FOREIGN KEY (room_id) REFERENCES rooms(id) ON DELETE CASCADE,
    CONSTRAINT fk_room_participants_user
        FOREIGN KEY (user_id) REFERENCES accounts_user(id) ON DELETE CASCADE,
    CONSTRAINT fk_room_participants_team
        FOREIGN KEY (team_id) REFERENCES teams_team(id) ON DELETE SET NULL,
    CONSTRAINT uq_room_participants_room_user
        UNIQUE (room_id, user_id)
);

CREATE TABLE IF NOT EXISTS items (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    category VARCHAR(100) NOT NULL,
    name VARCHAR(255) NOT NULL,
    price INTEGER NOT NULL DEFAULT 0,
    image_url TEXT,
    CONSTRAINT chk_items_price CHECK (price >= 0)
);

CREATE TABLE IF NOT EXISTS inventories (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id BIGINT NOT NULL,
    item_id INTEGER NOT NULL,
    quantity INTEGER NOT NULL DEFAULT 0,
    CONSTRAINT fk_inventories_user
        FOREIGN KEY (user_id) REFERENCES accounts_user(id) ON DELETE CASCADE,
    CONSTRAINT fk_inventories_item
        FOREIGN KEY (item_id) REFERENCES items(id) ON DELETE RESTRICT,
    CONSTRAINT uq_inventories_user_item
        UNIQUE (user_id, item_id),
    CONSTRAINT chk_inventories_quantity CHECK (quantity >= 0)
);

CREATE TABLE IF NOT EXISTS house (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id BIGINT NOT NULL,
    name VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_house_user
        FOREIGN KEY (user_id) REFERENCES accounts_user(id) ON DELETE CASCADE,
    CONSTRAINT uq_house_user UNIQUE (user_id)
);

CREATE TABLE IF NOT EXISTS placed_objects (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    house_id BIGINT NOT NULL,
    item_id INTEGER NOT NULL,
    position_data JSONB,
    CONSTRAINT fk_placed_objects_house
        FOREIGN KEY (house_id) REFERENCES house(id) ON DELETE CASCADE,
    CONSTRAINT fk_placed_objects_item
        FOREIGN KEY (item_id) REFERENCES items(id) ON DELETE RESTRICT
);

-- ==========================================================
-- 2조 과제 / 제출 / 평가
-- ==========================================================

CREATE TABLE IF NOT EXISTS assignment (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    description TEXT,
    due_at TIMESTAMP WITH TIME ZONE,
    is_required BOOLEAN NOT NULL DEFAULT FALSE,
    allow_late BOOLEAN NOT NULL DEFAULT FALSE,
    is_team BOOLEAN NOT NULL DEFAULT FALSE,
    created_by BIGINT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP WITH TIME ZONE,
    CONSTRAINT fk_assignment_created_by
        FOREIGN KEY (created_by) REFERENCES accounts_user(id) ON DELETE RESTRICT
);

CREATE TABLE IF NOT EXISTS submission (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    assignment_id INTEGER NOT NULL,
    student_id BIGINT,
    team_id BIGINT,
    target_rule VARCHAR(100) NOT NULL DEFAULT 'student_id XOR team_id',
    description TEXT,
    submitted_at TIMESTAMP WITH TIME ZONE,
    is_locked BOOLEAN NOT NULL DEFAULT FALSE,
    final_score INTEGER,
    CONSTRAINT fk_submission_assignment
        FOREIGN KEY (assignment_id) REFERENCES assignment(id) ON DELETE CASCADE,
    CONSTRAINT fk_submission_student
        FOREIGN KEY (student_id) REFERENCES accounts_user(id) ON DELETE RESTRICT,
    CONSTRAINT fk_submission_team
        FOREIGN KEY (team_id) REFERENCES teams_team(id) ON DELETE RESTRICT,
    CONSTRAINT chk_submission_target
        CHECK (
            (student_id IS NOT NULL AND team_id IS NULL)
            OR
            (student_id IS NULL AND team_id IS NOT NULL)
        )
);

CREATE TABLE IF NOT EXISTS submission_file (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    submission_id INTEGER NOT NULL,
    kind VARCHAR(100),
    file_url TEXT NOT NULL,
    file_name VARCHAR(255),
    file_size INTEGER,
    CONSTRAINT fk_submission_file_submission
        FOREIGN KEY (submission_id) REFERENCES submission(id) ON DELETE CASCADE,
    CONSTRAINT chk_submission_file_size
        CHECK (file_size IS NULL OR file_size >= 0)
);

CREATE TABLE IF NOT EXISTS ai_evaluation (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    submission_id INTEGER NOT NULL,
    score INTEGER,
    comment TEXT,
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_ai_evaluation_submission
        FOREIGN KEY (submission_id) REFERENCES submission(id) ON DELETE CASCADE,
    CONSTRAINT uq_ai_evaluation_submission UNIQUE (submission_id)
);

CREATE TABLE IF NOT EXISTS evaluation (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    submission_id INTEGER NOT NULL,
    evaluated_by BIGINT NOT NULL,
    score INTEGER,
    feedback TEXT,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_evaluation_submission
        FOREIGN KEY (submission_id) REFERENCES submission(id) ON DELETE CASCADE,
    CONSTRAINT fk_evaluation_evaluator
        FOREIGN KEY (evaluated_by) REFERENCES accounts_user(id) ON DELETE RESTRICT,
    CONSTRAINT uq_evaluation_submission UNIQUE (submission_id)
);

-- ==========================================================
-- 3조 PRD
-- ==========================================================

CREATE TABLE IF NOT EXISTS prds (
    prd_id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    template_id BIGINT,
    user_id BIGINT NOT NULL,
    round_id BIGINT NOT NULL,
    team_id BIGINT,
    title VARCHAR(255) NOT NULL,
    status VARCHAR(50) NOT NULL,
    deadline DATE,
    is_deleted BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_prds_user
        FOREIGN KEY (user_id) REFERENCES accounts_user(id) ON DELETE RESTRICT,
    CONSTRAINT fk_prds_round
        FOREIGN KEY (round_id) REFERENCES rounds_evaluationround(id) ON DELETE RESTRICT,
    CONSTRAINT fk_prds_team
        FOREIGN KEY (team_id) REFERENCES teams_team(id) ON DELETE SET NULL
);

-- ==========================================================
-- 4조 실제 근태 / 얼굴인식
-- ==========================================================

CREATE TABLE IF NOT EXISTS face_profile (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id BIGINT NOT NULL,
    status VARCHAR(50) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_face_profile_user
        FOREIGN KEY (user_id) REFERENCES accounts_user(id) ON DELETE CASCADE,
    CONSTRAINT uq_face_profile_user UNIQUE (user_id)
);

CREATE TABLE IF NOT EXISTS face_image (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    face_profile_id BIGINT NOT NULL,
    image_url TEXT NOT NULL,
    image_hash VARCHAR(255),
    is_primary BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_face_image_profile
        FOREIGN KEY (face_profile_id) REFERENCES face_profile(id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS attendance_record (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id BIGINT NOT NULL,
    attendance_date DATE NOT NULL,
    check_in_at TIMESTAMP WITH TIME ZONE,
    check_out_at TIMESTAMP WITH TIME ZONE,
    status VARCHAR(50) NOT NULL,
    source VARCHAR(50),
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_attendance_record_user
        FOREIGN KEY (user_id) REFERENCES accounts_user(id) ON DELETE CASCADE,
    CONSTRAINT uq_attendance_record_user_date
        UNIQUE (user_id, attendance_date)
);

CREATE TABLE IF NOT EXISTS face_recognition_log (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id BIGINT NOT NULL,
    face_profile_id BIGINT,
    attendance_record_id BIGINT,
    recognized_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    confidence NUMERIC(6,5),
    result VARCHAR(50),
    CONSTRAINT fk_face_log_user
        FOREIGN KEY (user_id) REFERENCES accounts_user(id) ON DELETE CASCADE,
    CONSTRAINT fk_face_log_profile
        FOREIGN KEY (face_profile_id) REFERENCES face_profile(id) ON DELETE SET NULL,
    CONSTRAINT fk_face_log_attendance
        FOREIGN KEY (attendance_record_id) REFERENCES attendance_record(id) ON DELETE SET NULL,
    CONSTRAINT chk_face_log_confidence
        CHECK (confidence IS NULL OR (confidence >= 0 AND confidence <= 1))
);

-- ==========================================================
-- 통합 채점
-- ==========================================================

CREATE TABLE IF NOT EXISTS results_scoreinput (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    calculation_run_id BIGINT NOT NULL,
    participant_id BIGINT,
    team_id BIGINT,
    source_type VARCHAR(100),
    source_id BIGINT,
    raw_score NUMERIC(10,4),
    weight NUMERIC(10,4),
    idempotency_key VARCHAR(255) NOT NULL,
    pushed_at TIMESTAMP WITH TIME ZONE,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT fk_scoreinput_calculation_run
        FOREIGN KEY (calculation_run_id)
        REFERENCES results_calculationrun(id) ON DELETE CASCADE,

    CONSTRAINT fk_scoreinput_participant
        FOREIGN KEY (participant_id)
        REFERENCES rounds_roundparticipant(id) ON DELETE RESTRICT,

    CONSTRAINT fk_scoreinput_team
        FOREIGN KEY (team_id)
        REFERENCES teams_team(id) ON DELETE RESTRICT,

    CONSTRAINT uq_scoreinput_idempotency_key
        UNIQUE (idempotency_key),

    CONSTRAINT chk_scoreinput_target
        CHECK (
            (participant_id IS NOT NULL AND team_id IS NULL)
            OR
            (participant_id IS NULL AND team_id IS NOT NULL)
        )
);

-- ==========================================================

CREATE INDEX IF NOT EXISTS idx_attendances_user_id
```

## 5. 무결성 규칙

### `results_scoreinput`

개인 또는 팀 중 하나만 대상으로 허용한다.

- 개인 점수: `participant_id IS NOT NULL`, `team_id IS NULL`
- 팀 점수: `participant_id IS NULL`, `team_id IS NOT NULL`
- 둘 다 NULL: 금지
- 둘 다 값 존재: 금지

### `submission`

- 개인 제출: `student_id`만 값 존재
- 팀 제출: `team_id`만 값 존재
- `student_id`와 `team_id` 동시 지정 금지

### `cg_users`

`cg_users.id = accounts_user.id` 구조로 사용자 계정 정보를 중복 저장하지 않는다.

### 근태 / 얼굴인식

- `attendance_record.user_id -> accounts_user.id`
- `face_profile.user_id -> accounts_user.id`
- `face_recognition_log.user_id -> accounts_user.id`

1조의 학습 출석 `attendances`와 4조의 실제 근태 `attendance_record`는 목적이 다르므로 별도 테이블로 유지한다.

## 7. 주의사항

본 산출물은 **신규 테이블 생성 SQL**이다.

현재 존재하는 테이블의 컬럼 변경, 이름 변경, 데이터 이전, 기존 FK 변경은 포함하지 않는다. 실제 Migration 단계에서는 현재 DB 스키마와 TO-BE ERD의 차이를 별도로 비교하여 `ALTER TABLE`, 데이터 이관, Django Migration을 작성해야 한다.

또한 실제 운영 DB에 직접 적용하기 전에 반드시 개발/검증 DB에서 실행 결과와 기존 데이터에 대한 영향을 확인한다.
