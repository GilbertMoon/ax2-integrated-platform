# 2026-09-02 Slack 연동 및 CI 검증 정리

## 1. Slack 공통 기능 배포 후 질의사항 확인

Slack 공통 기능 적용 전 연동 방식에 대해 질의하고 답변을 확인했다.

- `notifications` 모듈은 별도 패키지가 아닌 공통 프로젝트 코드로 제공되며 `develop` 브랜치에 반영 예정
- 서비스 DB의 `accounts_user.id`를 `send_slack_dm_ax()` 호출 시 사용
- Slack 사용자 매칭은 `accounts_user.email`과 Slack 사용자 이메일 기준
- Slack 사용자-서비스 사용자 연결 정보는 공통 `notifications` 앱에서 관리
- Slack 연동/사용자 동기화 관리자 경로는 `/notifications/slack/`
- 다수 사용자 대상 DM은 `send_slack_dm_ax_batch()` 사용
- Slack Rate Limit 재시도는 공통 기능에서 처리
