## 3. 최종 결과

### 3-1. Slack 사용자 매핑 기준

| 데이터 | 연동 기준 |
|---|---|
| AX User ID | 4조 AX2 Core `accounts_user` |
| Slack Member ID | 4조 `notifications_slackidentity` |
| Slack Email | Slack 계정 정보 |
| Slack Display Name | Slack 계정 정보 |
| 활성 상태 | `SlackIdentity.is_active` |

### 3-2. Slack 개인 DM 처리 기준

* 2조 LMS의 로그인 사용자 ID를 기준으로 Slack 사용자 매핑 정보를 조회
* `SlackIdentity`에서 해당 사용자의 Slack Member ID를 조회
* Slack Bot Token을 이용하여 DM 채널 생성
* 해당 Slack 사용자에게 개인 메시지 전송
* Slack 연동 실패가 과제 제출 자체의 실패로 이어지지 않도록 처리

### 3-3. 과제 제출 알림 기준

* 기존 과제 제출 완료 시 Slack 알림 기능을 개인 DM 방식으로 변경
* 과제 제출 완료 후 해당 학생의 Slack 계정으로 알림 전송
* 알림 내용에 과제 제출 완료 메시지 및 과제명을 포함

### 3-4. 변경 파일

* `apps/accounts_client/models.py`
  * `SlackIdentity` 읽기 전용 모델 추가

* `apps/notifications/slack.py`
  * Slack 개인 DM 전송 기능 구현
  * AX User ID → Slack Member ID 매핑 기능 구현

* `apps/student/views_submit.py`
  * 과제 제출 완료 후 Slack 개인 DM 전송 기능 연동
