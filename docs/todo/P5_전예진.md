### 이 담당자의 Issue 처리 순서

1. 각 Issue의 Deliverable / PR / Commit / 테스트 증거 확인

4. 내용이 같은 Issue가 중복이면 `DUPLICATE`
5. 실제로 아직 해야 할 일만 `ACTIVE` 또는 `BACKLOG`로 유지
6. ACTIVE Issue의 미완료 체크리스트만 개인 TODO의 현재 작업으로 반영
