|---|---|---|
| 1조 | 학습/출석 등 고유 기능 | 고유 기능 유지, 공통 User/Team은 Core 기준 연동 |

### 공통 데이터 기준
- User / Student / Team / TeamMember / Role 계열은 각 조에서 중복 생성하지 않고 공통 Core 기준으로 연동하는 방향으로 관리한다.
- 각 조의 업무 목적에 필요한 고유 데이터와 기능은 별도 Domain으로 유지한다.
- 이름이 유사하더라도 업무 목적이 다른 기능은 억지로 하나로 합치지 않는다.

### 출석 / 근태 기준
- 1조의 학습 출석과 4조의 실제 근태는 목적이 다르므로 별도 Domain으로 유지한다.
- 향후 근태/얼굴인식 기능은 학습 출석 데이터와 직접 통합하지 않고 별도 요구사항으로 관리한다.

### 통합/분리 판정 기준
- **통합**: 여러 조에서 공통으로 사용하는 Core 데이터/기능
- **유지**: 특정 조의 고유 업무 기능
- **분리**: 이름 또는 형태는 유사하지만 업무 목적이 다른 기능
- **폐기**: Core와 완전히 중복되어 별도 유지할 필요가 없는 구조
