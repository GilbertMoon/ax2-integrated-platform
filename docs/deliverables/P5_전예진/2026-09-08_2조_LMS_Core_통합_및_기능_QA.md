# 2026-09-08 2조 LMS Core 통합 및 기능 QA

## 1. 목적

- 2조 LMS 기능을 기존 4조 Core의 사용자·팀·회차 데이터 구조와 연결한다.
- LMS 과제 점수를 기존 Core 평가 결과 계산에 반영할 수 있도록 통합 구조를 구성한다.
- 통합 후 학생·튜터 주요 화면을 직접 점검하여 실제 기능 동작 여부를 확인한다.
- 전체 자동 테스트 및 Regression 테스트를 통해 기존 4조 기능에 영향이 없는지 확인한다.
- 통합 과정에서 발견된 오류를 별도 후속 QA 대상으로 정리한다.

## 2. 오늘 수행 내용

### 2.1 2조 LMS → 4조 Core 통합

2조 LMS가 별도의 사용자·팀 데이터를 독립적으로 사용하는 구조가 아니라 기존 4조 Core의 공통 데이터를 기준으로 동작하도록 연결하였다.

```text
4조 Core
accounts.User
    ↓
rounds.EvaluationRound
    ↓
teams.Team / TeamMembership
    ↓
2조 LMS
강의 / 과제 / 제출 / 점수
```

주요 통합 작업:

- 2조 LMS 기능을 통합 프로젝트의 LMS 영역에 연결
- LMS 모델 및 학생 강의 관련 View 연결
- LMS URL 구조를 통합 프로젝트 URL 구조와 연결
- LMS DB Router 구성 확인 및 연결
- 기존 Core 로그인 및 사용자 정보 연결
- 기존 Core Team / Round 데이터 연결
- LMS와 Core 사이의 연결 계층 구성
- LMS 점수 조회 Service 구조 연결

### 2.2 LMS 점수 → Core 평가 점수 반영 구조 구성

- 평가 회차별 LMS 반영 비율 관리용 `lms_score_weight` 추가
- 관련 DB Migration 작성 및 적용
- LMS 원본 점수 저장용 `lms_score_raw` 구조 추가
- LMS 0~100점 점수를 Core 평가 점수 체계에 맞게 변환하는 로직 연결
- 기존 평가 점수와 LMS 점수를 함께 계산할 수 있도록 계산 구조 수정
- LMS 점수 조회 Service와 Core 평가 결과 계산 연결

```text
LMS 과제 점수
    ↓
LMS 점수 조회 Service
    ↓
lms_score_raw
    ↓
0~100점 → Core 평가 점수 체계 변환
    ↓
회차별 lms_score_weight 적용
    ↓
기존 Core 평가 점수와 함께 최종 결과 계산
```

### 2.3 DB 및 기존 데이터 연동 점검

- Core User 데이터와 LMS 사용자 연결 확인
- Core Team 데이터와 LMS 팀 정보 연결 확인
- EvaluationRound와 LMS 데이터 연결 확인
- 신규 팀 편성 후 학생 소속 팀 데이터 재확인
- 기존 테스트 데이터에서 발생한 `내 팀` 조회 오류 확인
- 팀 관련 데이터 정리 후 조회 복구 확인

기존 테스트 데이터의 팀 구성 상태와 현재 회차의 팀 편성 데이터가 일치하지 않아 `내 팀` 조회 오류가 발생했으며, 이후 팀을 새로 편성하고 관련 데이터를 정리한 뒤 변경된 팀 구성원이 정상적으로 조회되는 것을 확인하였다.

### 2.4 자동 테스트 및 Regression 테스트

```text
462 tests passed
1 skipped
```

- 통합 후 전체 자동 테스트 실행
- 총 462개 테스트 통과
- 1개 테스트 Skip 확인
- LMS 통합으로 인해 기존 Core 테스트가 대량 실패하지 않는 것 확인
- 사용자 / 팀 / 평가 관련 주요 기능 Regression 기본 검증

### 2.5 학생/튜터 화면 QA

학생 계정과 튜터 계정으로 주요 LMS 화면을 직접 점검하였다.

- 학생 대시보드 접근
- 강의 목록/상세 조회
- 과제 목록/상세 조회
- 제출 및 Preview 화면 접근
- 현재 소속 팀 정보 조회
- 튜터 대시보드 접근
- 강의/과제 관리 화면 조회
- 학생 제출 현황 조회
- 팀/학생 정보 조회

학생/튜터 주요 화면을 합쳐 총 12개 화면에 대해 조회 및 접근 상태를 확인하였다.

1. 통합 코드 반영 후 전체 테스트를 실행한다.
2. 기존 Core 기능 관련 테스트 실패 여부를 확인한다.
3. LMS 관련 테스트 결과와 Skip 항목을 확인한다.
4. 통합으로 인해 기존 기능이 대량 실패하지 않는지 확인한다.

3. 강의/과제 주요 화면을 확인한다.
4. 제출/Preview 화면 접근을 확인한다.
5. 현재 팀 정보가 정상 조회되는지 확인한다.

### 튜터 기능

1. 튜터 계정으로 로그인한다.
2. LMS 튜터 대시보드에 접근한다.
3. 강의/과제 관리 화면을 확인한다.
4. 학생 제출 현황을 확인한다.
5. 팀/학생 정보가 Core 데이터와 일치하는지 확인한다.
