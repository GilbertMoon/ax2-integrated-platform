# AX2 Integrated Platform

## 1. 프로젝트 개요

본 프로젝트는 기존 **4조 평가 시스템을 Core(기준 시스템)** 로 유지하면서, 신규로 개발된 **1조·2조·3조 프로젝트의 기능을 통합**하고, 4조 신규 기능인 **근태 모듈·얼굴인식 모듈**을 추가하여 하나의 통합 교육 플랫폼으로 확장하는 프로젝트입니다.

최종적으로는 통합된 서비스를 **Windows 11 Pro PC 서버**에 배포하여 실제 운영 가능한 형태로 구성하고, 데이터베이스·로그·백업/복구·이미지 저장 등 기본 운영 체계까지 확인하는 것을 목표로 합니다.

### 주요 통합 범위

- **기존 4조 Core**: 회원, 학생, 팀, 평가, 평가회차, 결과, 팀편성
- **1조 기능**: 게임형 프로그래밍 학습 및 학습 관련 기능
- **2조 기능**: LMS, 강의, 과제, 제출, 피드백 관련 기능
- **3조 기능**: PRD 작성, 아이디어 구체화, AI Coach 관련 기능
- **4조 신규 기능**: 근태 관리, 얼굴 등록/인식, 인식 로그 및 이미지 데이터 수집
- **운영 환경**: Windows 11 Pro PC 서버 기반 통합 배포

> 통합 원칙: 공통 회원·학생·팀 등 Core 데이터는 4조 기준을 우선하며, 각 조의 고유 기능은 모듈 단위로 통합합니다. 단, 업무 목적이 다른 데이터(예: 1조 학습 출석과 4조 실제 근태)는 별도 도메인으로 유지합니다.

## 2. 진행 원칙

프로젝트는 한 번에 모든 기능을 합치지 않고 아래 순서로 단계적으로 진행합니다.

1. 기존 4조 시스템 정상 실행 및 Baseline 확인
2. 1·2·3·4조 ERD 및 공통 데이터 구조 비교
3. Core 데이터(User / Student / Team / Role 등) 기준 확정
4. 1조 → 2조 → 3조 순서로 기능 통합 및 단계별 테스트
5. 4조 신규 근태·얼굴인식 기능 개발 및 연동
6. 전체 통합 테스트 후 Windows 11 Pro PC 서버 배포

각 작업은 `TODO → DOING → REVIEW → DONE` 상태로 관리하고, 중요도는 `MUST / SHOULD / COULD` 기준으로 구분합니다.

## 4. 신규 근태·얼굴인식 모듈

4조 신규 기능은 실제 근태 관리와 얼굴인식 기능을 연결하여 다음 흐름으로 구성할 예정입니다.

```text
학생 얼굴 등록
    ↓
등원 시 얼굴 촬영
    ↓
얼굴 인식 및 학생 식별
    ↓
근태 기록 생성
    ↓
이미지 / 인식 결과 / 로그 저장
    ↓
향후 ML 학습·분석용 데이터 활용
```

얼굴인식 결과와 실제 근태 기록은 목적이 다르므로 데이터 구조를 분리하여 관리하고, 향후 ML 활용을 위해 이미지 경로, 촬영 시각, 인식 결과, confidence, 실제 확인 결과 등 필요한 메타데이터를 함께 저장하는 방향으로 설계합니다.

- 기존 4조 평가 기능 정상 유지

- 근태·얼굴인식 기능 추가 및 데이터 축적
- 핵심 Business Rule 및 기존 기능 Regression 확인
- Windows 11 Pro PC 서버에서 통합 시스템 실행
- 재부팅 후 서비스 재실행, DB Backup / Restore 및 기본 운영 절차 확인
- 프로젝트 구조와 실행 방법을 문서화하여 팀원 누구나 이해할 수 있는 상태 유지
